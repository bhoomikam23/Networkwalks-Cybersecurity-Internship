# Week 1 – Cybersecurity & Pentesting Lab Setup

As part of my Cybersecurity Internship at Networkwalks Technologies, I set up a virtual cybersecurity testing environment using VMware and Kali Linux.

## Tasks Completed

- Set up Kali Linux in VMware
- Configured the virtual machine networking
- Verified IP configuration
- Tested internet connectivity
- Verified DNS resolution
- Configured and validated the VMware network environment
- Troubleshot and verified the overall lab setup
