# Week 2 – Footprinting & Reconnaissance

## Project Module 1: Footprinting & Reconnaissance Attacks with Multiple Kali Tools

As part of my Cybersecurity Internship at Networkwalks, I completed a hands-on reconnaissance and footprinting project using multiple tools available in Kali Linux.

The objective was to gather publicly available information about the target domain and understand how different reconnaissance tools contribute to a security assessment.

## Tasks Completed

### Task 1 – WHOIS
Used WHOIS to find domain registration details, including registration information and name servers.

### Task 2 – WhatWeb
Used WhatWeb to fingerprint the web technologies used by the target website.

### Task 3 – Nslookup
Used Nslookup to resolve the domain name and identify its IP address.

### Task 4 – cURL
Used cURL to inspect the HTTP response headers of the website.

### Task 5 – WAFW00F
Used WAFW00F to identify whether a Web Application Firewall was protecting the website.

### Task 6 – DNSRecon
Used DNSRecon to enumerate publicly available DNS records.

## Tools Used

- WHOIS
- WhatWeb
- Nslookup
- cURL
- WAFW00F
- DNSRecon
- Kali Linux

## Learning Outcome

This project provided practical experience in reconnaissance and footprinting and helped me understand how publicly available domain, DNS, web technology, HTTP, and security infrastructure information can be collected during a security assessment.
